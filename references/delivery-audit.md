# 交付回对与验收可信度

> **适用边界**：只管「代码写完之后、说『做完了』之前」这一段，以及「下次来迭代」的衔接。
> 与 `build-guardrails.md` 的 G1-G8、主文件铁律 15 的发布前四道关**叠加执行，不替换任何一条**。
> 全部编号用 A1-A12，不占用主文件 23 条铁律、也不占用 G1-G8。
> 每一条后面的落地位置，都指向本仓库内可核对的文件。

---

## 一、为什么补这一段

主文件铁律 15 管的是「页面本身对不对」，但有三类失败发生在它够不着的地方：

| 失败 | 为什么四道关拦不住 |
|---|---|
| 交付的东西悄悄不是当初点头那一版 | 规则检查只问「合规吗」，不问「是他同意的那件事吗」；降级成一堆静态图照样对比度满分、零溢出 |
| 验收脚本压根没跑到目标代码 | 「工具跑过了」和「代码被检过了」是两回事。静态分析器读不到单文件 HTML 里的内联 `<script>` 时，输出照样是成功 |
| 下次迭代拿不到上一次的定义 | 配置和实际工程不同步，第二次改动从错误的基线出发 |

静态分析器按文件清单取源码，单文件 HTML 里内嵌的 `<script>` 不在清单上，
**内联脚本几乎全部不会被覆盖**，被完整解析的只有独立 `.js` 文件。
这是单文件全内联架构的固有盲区，不是工具坏了。
所以把「扫描器没报错」当成「页面已验证」，在这套架构下必然是假绿。
CDN 脚本、在线字体、图床这类外链资源与零外链地基冲突，不采纳；
但**不依赖外链、可验证的通用护栏不受此限**，见 A11 / A12 与第四节的判定口径。

## 二、补进来的 12 条

**A1 承诺回对：把当初点头那一句逐条对回成品，任何一条缺失都是 P0。**
生成前写给用户的那句「你会看到什么」（主文件第二节「先给一版让他挑错」），
交付前原样贴回来，逐项打勾：描述过的效果是否**真的存在**，不是「效果差不多」。
做不出来的效果**必须说出来重新谈**，不许静默降级。
典型：说好「背景缓慢漂移」，实现不动了就压成一张静态图——静态图对比度高、无溢出、零 jank，
四道关全过，但用户拿到的是他没同意过的东西。
落地位置：接在铁律 15 四道关**之前**，作为第 0 道。

**A2 页面真的渲染了吗：本地资源逐条解析，并确认探测器本身跑过。**
- 所有本地 `href` / `src` / `url()` 都要指向**磁盘上真实存在的文件**；跳过 `http(s):` / `data:` / `#` / `mailto:`，
  根相对 `/xxx` 静态检查判断不了，手工核。
- **探测器没找到、没运行，就是没通过**，不许记成「无问题」。输出里必须能点名它检了哪些文件。
- 按自己的构建清单走一遍：样式、脚本、每个资源，**写了计划 ≠ 文件在盘上**。
- 单文件全内联架构下，外部扫描器读不到内联脚本（见第一节），所以验收必须以
  主文件铁律 15 的 jsdom 回归 + 注入式浏览器探针为准，不能只信静态扫描结果。
- 静态检查只能判「结构对不对」，**好不好看他一眼就知道，耗时一秒**。别替他开浏览器下结论，
  如实说「我没打开看」。

**A3 能力探测统一在顶部读一次，按效果分支。**

```js
const RM   = matchMedia('(prefers-reduced-motion:reduce)').matches;
const FINE = matchMedia('(hover:hover) and (pointer:fine)').matches;
// 每个动效各自分支：if (RM) 设终态 else 走动画
```

- 跟指针有关的动效（磁吸、跟随光标、倾斜、悬停展开）再套 `FINE`，触屏上不许触发。
- 每个动效都要有**终止态**：进度条 100%、数字最终值、卡片在最终位置、展开区保持展开。
  只把动画时长压成 0 而状态没落地，等于发布一个卡在中间态的坏版本。
- CSS 兜底同时保留：`@media (prefers-reduced-motion:reduce){*{animation-duration:.01ms!important;transition-duration:.01ms!important}}`。
- 手写图表的入场动画同样要有终态分支。
与主文件 `visual-qa.md` 第八节叠加：那里讲「为什么」，这里给统一写法。

**A4 无障碍与性能补齐数值。**
- 对比度 WCAG AA：正文 ≥ 4.5:1，大字与图形 ≥ 3:1；按钮压在图上要加遮罩或描边，
  placeholder 与 focus ring 也算在内。主文件铁律 15 的 3:1 是下限，正文按 4.5:1 再提一档。
- 每个可交互元素有**可见的 focus 态**，导航和主操作键盘可达。
- 只动 `transform` / `opacity`，`will-change` 少用；重引擎延迟加载；
  移动端用 `min-h-dvh` 不用 `100vh`；响应式图片；CLS < 0.1。
- 多列区块逐段声明窄屏怎么塌，触控目标 ≥ 44px。
落地位置：`references/visual-qa.md` 第一、八节。

**A5 每日重复项与临时项必须分开存。**
有「固定行程 / 每日打卡 / 周期模板」类数据时，模板单独存一份，每天生成当天实例：
- 第二天打开，**重复项自动重置为未勾选**
- **临时加的今日待办按逾期规则顺延或清空**（见 G3），不混进模板
不做这个区分，用户第二天看到的是一张昨天勾满的死页面，这个台子就废了。
落地位置：骨架 `examples/minimal/index.html` 的种子与读取段。

**A6 配置与变更记录是迭代入口，改完必须回写。**
迭代时先读配置（功能清单、风格参数、数据结构、部署状态），改代码、跑验收，**然后同步更新配置 + 变更记录**。
最容易漏的就是回写这一步：配置与工程不同步，下一次迭代从错误基线出发。
- 判断是不是旧骨架：搜 `@media` 和统一存储 API，两者都缺即旧版；旧版升级是**重建 + 搬逻辑**，不是逐处打补丁。
- 重建前**先让用户导出一份备份**，这一步不许跳。
- 数据在 localStorage 命名空间里、跟 HTML 文件分离，域名和 key 不变时换 HTML 不丢数据——但别拿这条当不备份的理由。
落地位置：`scripts/wbconfig.example.py`、`examples/minimal/README.md`。

**A7 风格靠能真点的页面定，不靠文字描述，也不靠生成图。**
让用户在**装着他自己的功能、手机上能真打开真点**的页面上挑风格。
生成图画的界面往往好看但实现不出来，制造预期落差；纯文字描述同样定不了手感。
落地位置：主文件第二节「先给一版让他挑错」、阶段 1 规模闸门。

**A8 交付前扫一遍廉价感清单（零成本项）。**
- 装饰性的长破折号、渐变文字、默认磨砂玻璃、紫色辉光
- 每个区块都挂小标题、`01 · 02 · 03` 编号当默认骨架、六张一模一样的「图标 + 标题 + 说明」卡片
- 没有真实来源的假精确数字（`92%`、`4.1×`）——与主文件红线禁编数字同一件事
- 按品类条件反射套配色（手作用米色黄铜、AI 用紫光）；字体不假思索就用默认那两三套
- 本该有图的位置空着（首屏、封面、空状态）；反过来，**用户没点头就冒出来的图同样不行**
与主文件 `visual-system.md` 第八节叠加：那里管色彩与字重，这里管「一眼 AI 味」。

**A9 图表的高度就是数值：先算数，再画形。**
骨架 `examples/minimal/index.html` L485-502 已经是正确写法（`base=160`、`bh=v/mx*maxh`、数值与日期标签都在），
这里把它反提成规则，免得从 0 搭新台子时只带了外观、没带口径。
- 柱高 = `value / max * 可用高度`，**基线锚在 0**。绝不用 `(value-min)/(max-min)`：柱子的面积在编码数值，
  截断基线会把很小的差距放大成假结论；折线、散点才允许减去 min。
- 先算几何再上动画。把柱子写成撑满容器、再用 `scaleY:0→1` 长出来，会变成一排一样高的条形码——
  动画好看，数值没进几何。动效只能作用在**已经算好高度**的盒子上。
- 每根柱都要有 x 轴标签（密集时隔 N 个标一个，不许竖排）、**数值默认可见**（不能只靠 hover 才看得到）、
  多系列要有图例；时间与趋势用线或面积，不用柱。
- 数据本来就平，就换成一条线 + 一个大差值数字，别画一排等高柱硬撑。
- 图表要有文字或表格兜底，屏幕阅读器和色弱用户能读到同一组数；
  骨架里的 `role="img"` + `aria-label` 是起点，不是终点。
- 拦发布的「坏柱体检」：所有柱一样高 / 全部顶到容器顶 / 柱比间隙还细 / 没有轴标签 /
  分组图没图例 / 拿柱画趋势 —— 命中任意一条就不许发。
与铁律 1-7 是同一件事：图不好看是小事，**图把数说错了是红线**。
落地位置：`references/visual-qa.md`、骨架 L485 手写图表段。

**A10 组件八态、几何四禁、数字排版：这些是排版里最便宜也最常漏的一层。**
它们跟落地页的大图、在线字体、滚动特效无关，工具型页面一样要过。

- **每个可交互控件写全八态**：`default`；`hover` 用 `@media (hover:hover)` 包住，别在触屏上粘住；
  `focus-visible` 要有可见 ring（对相邻面 ≥3:1），**不许给它加出现动画**，键盘用户要落焦即见；
  `active` 按下态（1px 位移或填色加深，最常漏的一个）；`disabled` 必须三通道同时给——
  `opacity` + `cursor:not-allowed` + 原生 `disabled`（或 `aria-disabled`），只降透明度是「一个褪色的可用按钮」；
  `loading` **预留最终宽度**，换标签不许把布局重排，超过约 300ms 才出反馈；
  `error` 要写清原因和怎么修，不许只写「无效」；`success` 屏幕上已经看得见就别再弹提示。
- **四条几何禁令**（全是会挤动邻居的）：状态切换**不许改 `border-width`**，改背景色/描边色/`outline`/阴影；
  focus ring 用 `outline` + `outline-offset` 不用 `border`，静止时预留 `outline:2px solid transparent`；
  **同一行表单控件统一高度**（38px 输入框配 44px 按钮是最常见的调校味）；
  **预留提示/错误槽位** `min-height:1lh`，报错不许把整页往下推。
  落地：骨架 `examples/minimal/index.html` 的表单段、`references/visual-qa.md` 的 44px 触控。
- **数字与文字排版**：表格和指标里的数字右对齐 + `font-variant-numeric:tabular-nums`
  （骨架 L125 / L132 本来就是这么写的，这里反提为规则）；小标签用宽字距形成反差，
  跟大标题的负字距反向；标题里要强调只用**同族**的粗体或斜体，别塞一个衬线词进去；
  长标题用 `text-wrap:balance`、正文 `pretty` 防孤字。
- **多必填项表单要有「提交前检查卡」**：每行写**实际值**，不写「已填写」这种空状态；
  不合格行带真能点的跳转（滚到该段并聚焦该字段）；状态随输入实时重算，不等提交失败才填；
  通过 / 阻断 / 建议三态分开，建议不阻断且视觉要跟阻断区分；
  **不许只把提交按钮置灰当反馈**——要么按钮可点、点完在这里列问题，要么置灰且这里写清为什么。
  与主文件「拦截和缺项用常驻错误区指名缺哪项」「长得像链接就必须真能点」是同一件事。

**A11 真要加重动效或画布时，先过这七条。**
`visual-system.md` 第六节与 L181 已经允许小角度倾斜卡片（±3 / ±4 度），
`visual-qa.md` 第八节与 A3 管的是终止态和触屏分支；这里补的是更上一层的取舍与兜底。

- **默认留在 CSS 变换**。拿不准就别上渲染库：单文件全内联下引入外部库会拆掉地基，
  而 CSS 变换覆盖绝大多数「想要一点立体感」的需求，还不会掉帧。
- **一页只留一个重动效**（画布、粒子、透视场算重动效）。倾斜卡片、翻转、画布叠在一起就是噪声。
- **渐进增强**：把动效层整层删掉，页面仍然完整可读、可点、数据仍然在。动效是增强不是结构。
  跟 A1 是同一件事——不能因为关了动画就丢内容。
- **画布按 DPR 适配并夹到 2**（`canvas.width = innerWidth * Math.min(devicePixelRatio, 2)`），
  否则高分屏一片糊；帧率掉了先降分辨率或粒子数，不许降功能。DOM 动效只动 `transform` / `opacity`。
- **画布必须有静态兜底画面**：`prefers-reduced-motion` 停在静帧，库没加载、设备不支持时也不许留一块空白。
  A3 给的是「每个动效各自有终止态」，这里补的是「终止态到底长什么样」。
- **触屏压平要有明确静止态**：指针跟随类交互在触屏上不是「没反应」，而是本来就平、本来就在终态；
  别留一个只有鼠标能触发的桌面交互孤零零挂在手机上（`FINE` 见 A3）。
- **两个几何坑**：透视容器上的 `overflow:hidden` 会裁掉朝观察者弹出的 `translateZ`；
  翻转面要 `backface-visibility:hidden`。
- **交付前查一次「调用了页面里没有的东西」**：库没加载、函数没定义，页面不报错、只是静默什么都不发生，
  比报错更难发现。与 A2 的「探测器必须确认真跑过」是同一类假绿。

落地位置：`references/visual-system.md` 第六节 / L181、`references/visual-qa.md` 第八节、A3。

**A12 文字可读性的几个数值：A10 给了写法，这里给数。**
系统字体栈一条就够，不引在线字体——下面这些数值跟用哪个字体无关，照样成立。

- **相邻字号档比值 ≥1.25**。1.1 的阶梯在屏幕上几乎看不出层级，读起来就是浏览器默认尺寸。
- **正文行长 65–75ch**（`max-width:70ch` 一类），宽屏上别让一行拉到 120 字。
- **显示字重与正文要拉开极端对比**：800 / 900 对 300，**同族即可**，不靠换字体制造层级；
  与 `visual-system.md` 第八节的「字重张力」是同一条，这里补上数值下限。
- **数字、时间戳、标签用等宽 + `tabular-nums`**（写法见 A10），正文不用等宽。
- **默认字体要主动避开**：随手挑中最常见的那一两个无衬线体，本身就是「没设计过」的信号；
  换不到别的字体时，靠字重阶梯、字距和行长分层也算过关，不必为了换字体去引外链。
- 长标题 `balance`、正文 `pretty`（A10 已有）配合 65–75ch 一起看，孤字和长行往往同时出现。

## 三、一轮交付里怎么用

1. 代码写完 → **A1 承诺回对**（第 0 道）
2. **A2** 资源解析 + 确认探测器真的跑过 → 再进主文件铁律 15 四道关
3. **A3 / A4** 动效终态与无障碍数值，与 `visual-qa.md` 一起过；有图表按 **A9** 过坏柱体检；
   有重动效或画布按 **A11** 过兜底与静帧
4. **A8** 廉价感清单 + **A10** 组件八态、几何四禁、数字排版 + **A12** 文字数值扫一遍
5. 有周期数据按 **A5**，定风格按 **A7**
6. 交付时按 **A6** 回写配置与变更记录；如实说明哪些检查没跑、哪些没打开看

## 四、明确的取舍

| 不做 | 为什么 |
|---|---|
| 引入 CDN 脚本 / 在线字体 / 图床 | 与主文件铁律 1「单文件全内联、零外链」冲突 |
| 用截图或像素比对判视觉 | 主文件 `visual-qa.md` 已裁决：用对比度探针 + 溢出档位，不用像素比对 |
| 把展示型页面的**观感**套到工作台 | 工作台是每天打开的工具，一屏定生死的大图、滚动叙事、超大字特写都用不上 |
| 按行业或人群查一张固定风格表 | 主文件铁律 21 要求按数据结构配模块；`anti-sameness.md` 五轴 + 用过清单已有硬约束（新台子与最近几条至少 3/5 轴不同），查表反而会把每次产出拉回同几种默认 |
| 写「多少个案例验证」这类资历数字 | 主文件第七节红线：禁虚构成绩，只写可核对的规则 |
| 用外部静态扫描结果替代 jsdom 回归 | 内联脚本读不到，扫描器成功 ≠ 页面已验证 |

> **判定口径（别再一刀切）**：不取的是**观感、外链资源、资历数字**，
> 不是那些效果背后的**降级、兜底、无障碍、几何、数值**规则。
> 一个效果出自落地页，不等于它的护栏也只能用于落地页。
> 判「不取」之前先问三句：它依不依赖外链？它能不能被验证？工作台里有没有同类控件？
> 三句里但凡有一句指向「不依赖 / 能验证 / 有同类」，就该按 A11 / A12 的方式把护栏取回来。

> 本文件是**加法**：主文件 23 条铁律、五阶段、访谈、对抗性审查、协作铁律、红线，
> 以及 `build-guardrails.md` 的 G1-G8，一条未删未改。
