# 黄桃子工作台搭建师

搭建一个"他自己每天会打开"的工作台：单文件网页，数据靠脚本定时抓，  
抓断了页面自己喊出来，能发布上线、能加到手机桌面当 App 用。

参考实现是一个自媒体创作台（对标情报 / 作品数据 / 选题 / 待办，40+ 板块），  
但方法本身不限于这个行业。

---

## 它跟普通工作台 skill 有什么不一样

| 常规版          | 这个 skill 多做的                                  |
| ------------ | --------------------------------------------- |
| 出一份需求、生成一版页面 | 生成之后**长期迭代**：改哪一块、怎么改不破坏别处，有成文规则              |
| 数据在页面里手填     | 数据由**脚本定时抓取**注入，页面只负责显示                       |
| 数据抓不到就显示空    | 抓不到会**明确说出来**：哪个源、断了几天、怎么修（断更告警）              |
| 好看就行         | 有**验收工具链**：jsdom 回归 + 对比度探针 + 五档移动端溢出 + 发布前自检 |
| 一套配色         | **双轴皮肤**（4 套 × 明暗），每套都过对比度探针                  |

一句话：**常规方式擅长"第一次生成"，这个 skill 擅长"生成之后还能不能长期迭代下去"。**

## 安装

这个 skill 是给 WorkBuddy 用的，放到 WorkBuddy 的「用户级 skills 目录」即生效。

**方式一：Git 克隆（推荐，方便日后更新）**

把仓库克隆到本机 WorkBuddy 的 skills 目录：

- Windows：`C:\Users\你的用户名\.workbuddy\skills\`
- macOS / Linux：`~/.workbuddy/skills/`

Windows 在 Git Bash 里执行：

```
cd "/c/Users/你的用户名/.workbuddy/skills"
git clone https://github.com/HTZ-luck/workbench-builder.git
```

> 克隆出的文件夹名是 `workbench-builder`，WorkBuddy 靠里面的 `SKILL.md` 识别 skill，文件夹名不影响使用，想改中文名也行。

**方式二：下载 ZIP 手动放**

1. 仓库页点 `Code → Download ZIP`
2. 解压放到上面的 skills 目录
3. 重启 WorkBuddy（或刷新技能列表）

**确认装好**：对话里说"帮我搭个工作台"，若它按本 skill 流程启动，就装对了。

## 怎么用

触发条件写在 `SKILL.md` 的 frontmatter 里（说"帮我搭个工作台"这类话就会启动）。  
启动后它按自己的流程走：定打开时刻 → 定首屏那句话 → 认数据结构 → 生成 → 四道验收 → 发布。

两种入口：

- **新建**：从 `examples/minimal/` 那份最小骨架出发
- **迭代**：已有工作台，说"加个 XX" / "换个配色" / "改一下"，走迭代不重新访谈
